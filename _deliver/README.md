- **当前有效**：最新任务、尚未被替代的正式报告，列在第一节。
- **历史**：被后续版本替代的报告保留，标"历史，已被 X 替代"，不删除。
- **索引维护**：新增报告时同步更新本文件；不额外创建 `CONTEXT_INDEX.md` 等重复索引。
- **引用规范**：仓库 owner/repo、分支、完整 commit SHA、相对路径、GitHub 链接缺一不可。
