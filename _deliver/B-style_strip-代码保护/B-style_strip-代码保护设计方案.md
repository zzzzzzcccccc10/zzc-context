## 二、识别设计（四个入口，区间合并去重）

### 2.1 入口 A1：关键字语句

行首（允许前置空格）匹配：

`async def|def|class|import|from|return|yield|raise|assert|print|for|if|elif|else|while|try|except|finally|with|lambda|@[\w.]+`

并要求：

- 关键字后是空格/括号/冒号（`print(` 无空格才算；`print (` 带空格视为说明，不进入）；
- 行内含代码符号（`(`、`=`、`->`、`{`、`[`）或下一行以 2+ 空格/Tab 缩进；
- 不是列表/引用/表格；
- `if/for/while/with/def/class` 只有 `:` 结尾、行内无代码符号、下一行不缩进 → 视为自然语言（`if you have time: 我们聊聊`），不进入。

覆盖：`import os`、`from pathlib import Path`、`return x`、`raise ValueError(...)`、`assert x` 等。

### 2.2 入口 A2：赋值语句

行首匹配：

`^\s*[A-Za-z_]\w*(\s*,\s*[A-Za-z_]\w*)*\s*=\s*`

（顶层或缩进均可；`==` 不算赋值，需排除 `^[^=]*==`）。

覆盖：`x = 1`、`y = 2`、`a, b = 1, 2`。

### 2.3 入口 A3：调用语句

行首匹配：

`^\s*[A-Za-z_][\w.]*\s*\(`

覆盖：`print(add(2, 3))`、`foo()`；`print (` 带空格不进入（视为说明）。

### 2.4 入口 A4：纯缩进块（带代码特征门槛）

- 一行以 2+ 空格或 Tab 缩进，连续 ≥2 行；
- 且块内**至少 2 行**含代码特征：`=`、`(`、`:`、`#`、`[`、`{`、`->`；
- 且不是列表/引用/表格；不与围栏/行内代码重叠；
- 从第一行缩进行开始，到第一个非缩进行（或空行后非缩进行）结束；空行保留。

**自然语言反例（不保护）**：整段普通说明每行缩进 4 空格、无 `=`/`(`/`:`/`#` 等 → 不满足代码特征，正常 restyle。

### 2.5 块扩展与嵌套缩进（4→8→4）

从起始行 i 开始，基准缩进 `base = indent(i)`：

- 行缩进 > base → 块内（4→8）；
- 行缩进 == base 且匹配 A1/A2/A3 → 块内（8→4）；
- 行缩进 < base → dedent，块结束；
- 空行保留；若下一行缩进 < base → 结束于空行前；
- 非缩进但匹配 A1/A2/A3 或闭合行（`^\s*[)\]}]+;?$`）、`else/elif/except/finally` → 块内；
- 其它 → 结束。

示例（base=0）：

```
def add(a, b):          # 起始
    if a > b:           # 4
        return a        # 8
    return b            # 4
                        # 空行保留
print(add(1, 2))        # 0，匹配 A3 → 块内
```

### 2.6 行内代码

- 单反引号成对，长度 1：`` `code` ``；
- 双反引号成对，长度 2：`` ``code`` ``（内容可含单反引号）；
- 未闭合：保护到行尾，不跨行；
- 不处理反斜杠转义（明确：`` \` `` 按字面反引号配对）；
- 围栏内不识别行内代码。

## 三、分段与边界（v4）

### 3.1 逐行处理，保留换行

`restyle_noncode` 逐行处理，不在代码区间边界 `strip`；非代码段与代码段拼接保留原文换行。

### 3.2 边界空行

- 代码区间前后各 1/2/3 个空行**原样保留**；
- `squash_blank` 只在非代码段内执行，不跨代码区间边界；
- 测试：代码前后 1/2/3 空行，断言最终输出空行数量与原文一致。

### 3.3 CRLF

- 保持原文换行格式：代码区逐字节（含 `\r\n`）；普通文本的 `\r\n` 保留，不统一成 LF；
- 分段/逐行处理时保留 `\r`；
- 测试：CRLF 普通文本 + 无围栏代码混排，断言代码区逐字节、普通文本 CRLF 不丢。

### 3.4 扫描异常与 max_len

- 扫描异常：返回整条原文，不执行 restyle；
- `max_len`：先判断 `len(text) > max_len` → 原样返回（旧行为）。
