## 〇、v2 阻断项与返修

1. **分段边界换行**：`restyle_noncode` 内部 `strip()` 会删掉代码区间前后的换行，导致普通文本和围栏/代码粘连。v3 改为“逐行处理、保留原换行、代码区间前后不 strip 跨段空白”，并增加“代码前后均有普通文本”的整段输出测试。
2. **无围栏缩进块入口**：v2 只要求“代码关键字起始行”，却把“仅缩进、无关键字”列进验收矩阵，没有算法支撑。v3 增加**独立缩进块入口**（连续 ≥2 行缩进，不需要关键字），与关键字入口并列；矩阵中两类都有对应入口。

## 一、目标

保持 `style_strip` 的短消息口语化行为，同时逐字节保护代码内容；不改变 `max_len` 旧行为；不扩展到 `multi_bubble` / `rule_guard`。

## 二、首版语言范围

- **支持**：Python 风格代码（`def` / `class` / `import` / `from` / `for` / `if` / `elif` / `else` / `while` / `try` / `except` / `finally` / `with` / `return` / `yield` / `raise` / `assert` / `print` / `lambda` / `@装饰器`）。
- **不支持**：JS / C / HTML / Rust 等无围栏代码块（只保护围栏与行内代码，不做无围栏识别）。
- 目的：首版只承诺 Python 风格，避免“看起来像代码就保护”的误判。

## 三、识别设计

### 3.1 围栏代码

``` / ~~~（长度 ≥3，同字符关闭；关闭行只允许空白；CRLF `\r?$`；未闭合保护到末尾；四反引号开、三反引号关不算关闭）。

### 3.2 无围栏入口 A：关键字起始行

起始行需同时满足：

1. 行首（允许前置空格）匹配 Python 关键字：`async def|def|class|import|from|for|if|elif|else|while|try|except|finally|with|return|yield|raise|assert|print|lambda|@[\w.]+`；
2. 关键字后是空格/括号/冒号（`print(` 无空格才算；`print (` 带空格视为说明，**不进入**）；
3. 行内含代码符号之一：`(`、`=`、`->`、`{`、`[`，或下一行以 2+ 空格/Tab 缩进；
4. 不是列表、引用、表格；
5. 对 `if/for/while/with/def/class` 等，若只有 `:` 结尾但行内无 `(`/`=`/`->`/`{`/`[` 且下一行**不缩进**，视为自然语言（如 `if you have time: 我们聊聊`），不进入。

**块扩展**（从起始行）：

- 包含起始行；
- 缩进行 → 包含；
- 空行 → 暂存；下一行仍是缩进行/代码行/闭合行 → 保留并继续，否则结束于空行前；
- 非缩进但匹配关键字、闭合行（`^\s*[)\]}]+;?$`）、`else/elif/except/finally` → 包含；
- 其它 → 结束。

### 3.3 无围栏入口 B：纯缩进块（v3 新增）

独立入口，**不要求关键字**：

- 一行以 2+ 空格或 Tab 缩进，且连续 ≥2 行同样缩进；
- 且不是列表（`^\s*[-*+]\s`）、不是引用（`^\s*>`）、不是表格（`^\s*\|`）、不与围栏/行内代码重叠；
- 从第一行缩进行开始，到第一个非缩进行（或空行后非缩进行）结束；空行保留。

真实 69 字符样本由入口 A 覆盖（首行 `def`、末行 `print`）；纯缩进块（无关键字）由入口 B 覆盖。两个入口可并存，区间合并去重。

### 3.4 行内代码

- 单反引号：成对同长度 1，`(?<!`)`([^`\n]+)`(?!`)`；内容可含普通字符；
- 双反引号：成对同长度 2，`` (?<!`)``([^`\n]+)``(?!`) ``；内容可含单个反引号；
- 未闭合：保护到**行尾**（不跨行）；
- 不处理反斜杠转义（明确：`` \` `` 不视为转义，按字面反引号配对）；
- 围栏内不再识别行内代码；行内代码不跨行。

## 四、分段与边界换行（v3 返修）

### 4.1 逐行处理，不 strip 整段

`restyle_noncode` 改为：

```python
def restyle_noncode(seg):
    lines = seg.split("\n")
    out = []
    for i, line in enumerate(lines):
        out.append(restyle_line(line))   # 行内标点/空格处理，不 strip 整段
        if i != len(lines) - 1:
            out.append("\n")
    return "".join(out)
```

- `restyle_line` 保留原来的 `fix_punctuation`、`[ \t]{2,}→1`、行首清理；`strip()` 只作用于单行；
- 分段拼接时保留原文换行，不在代码区间边界做 `strip`；
- `squash_blank` 只在非代码段执行，且不跨代码区间边界。

### 4.2 边界策略

- 代码区间 `[s, e)` 原样保留（含首尾换行）；
- 非代码段 `[last, s)`、`[e, next)` 逐行处理，段尾换行保留；
- 若代码区间前一行是普通文本、后一行也是普通文本，最终输出必须是 `普通文本\n代码\n普通文本`，不得粘连成 `普通文本代码普通文本`。

### 4.3 必测（整段输出，不只代码区间）

```
说明一
```python
def add(a, b):
    return a + b
```
说明二
```

期望：`说明一\n` + 原样围栏块 + `\n说明二`，代码前后换行不丢、不粘连。

无围栏样本：

```
前文
def add(a, b):
    return a + b
后文
```

期望：`前文\n` + 原样代码块 + `\n后文`。

## 五、扫描异常与 max_len

- 扫描异常：返回**整条原文**，不执行 restyle（v2 决定保留）；
- `max_len`：先判断 `len(text) > max_len` → 原样返回（旧行为）；只有 `≤ max_len` 才进入保护 + restyle。
