- 不支持 JS/C/HTML/Rust 等无围栏代码块；这类语言只保护围栏/行内代码；

## 二、识别设计（四个入口，区间合并去重）

### 2.1 入口 A1a：自包含语句（不需要下一行缩进）

行首匹配：

`^\s*(import|from|return|yield|raise|assert)\b`

且行内非空、不是列表/引用/表格。覆盖：

- `import os`
- `from pathlib import Path`
- `return result`
- `yield item`
- `raise ValueError("x")`
- `assert x > 0`

> 这些语句本身完整，不要求下一行缩进；作为独立行也进入保护。

### 2.2 入口 A1b：块起始语句（需要缩进或代码符号）

行首匹配：

`^\s*(async\s+def|def|class|if|elif|else|for|while|try|except|finally|with|lambda)\b`

且满足：

- 行内含 `:` / `(` / `=` / `->` / `{` / `[` 之一，或下一行以 2+ 空格/Tab 缩进；
- `if/for/while/with/def/class` 只有 `:` 结尾、行内无代码符号、下一行不缩进 → 自然语言（`if you have time: 我们聊聊`），不进入。

### 2.3 入口 A2：赋值语句

`^\s*[A-Za-z_]\w*(\s*,\s*[A-Za-z_]\w*)*\s*=\s*`

排除 `==`（`^[^=]*==`）。覆盖 `x = 1`、`a, b = 1, 2`。

### 2.4 入口 A3：调用语句（函数名后紧跟 `(`，无空格）

`^\s*[A-Za-z_][\w.]*\(`

- `print(add(2, 3))`、`foo()` 进入；
- `print (x)`（函数名后有空格）**不进入**（视为说明）。

### 2.5 入口 A4：纯缩进块（代码特征门槛）

- 连续 ≥2 行以 2+ 空格或 Tab 缩进；
- 块内**至少 2 行**含代码特征：`=`、`(`、`#`、`[`、`{`、`->`（**不含冒号**）；
- 不是列表/引用/表格；不与围栏/行内代码重叠；
- 从第一行缩进行开始，到第一个非缩进行（或空行后非缩进行）结束；空行保留。

**自然语言反例（不保护）**：

- 连续缩进的普通说明，每行只有中文/英文句子、无上述特征；
- 含两个冒号的说明：`我想说：第一：我们要出发了`（全角冒号不算特征）；
- `Note: this is a note`（ASCII 冒号不算特征）。

### 2.6 块扩展与 base=4 续块（4→8→4）

从起始行 i 开始，`base = indent(i)`：

- 行缩进 > base → 块内（4→8）；
- 行缩进 == base 且匹配 A1a/A1b/A2/A3、闭合行（`^\s*[)\]}]+;?$`）、`else/elif/except/finally` → 块内（8→4，续块）；
- 行缩进 < base → dedent，结束；
- 空行保留；若下一行缩进 < base → 结束于空行前；
- 其它 → 结束。

**base=4 专项示例**：

```
def f(a):
    if a:                 # base=4，块内
        print(a)          # 8
        return a          # 8
    return 0              # 4，匹配 A1a → 续块（不提前结束）
```

### 2.7 行内代码

- 单反引号成对，长度 1；双反引号成对，长度 2（内容可含单反引号）；
- 未闭合：保护到行尾，不跨行；
- 不处理反斜杠转义；围栏内不识别行内代码。

## 三、分段与边界（v5）

### 3.1 逐行处理，保留行结束符

- 用 `splitlines(keepends=True)` 切行，保留每行 `\n` / `\r\n`；
- 非代码段逐行处理：`line` 去掉行结束符后处理，再拼回原结束符；
- 代码区间按原字符串切片（含 `\r\n`），逐字节保留；
- 段间拼接不 `strip`。

### 3.2 边界空行

- 代码区间前后 1/2/3 空行原样保留；
- `squash_blank` 只在非代码段内执行，不跨边界。

### 3.3 CRLF 字节级

- 混排输入（普通文本 `\r\n` + 代码 `\r\n`）处理后，**整个最终输出**与期望按字节比较：`out.encode("utf-8") == expected.encode("utf-8")`；
- 代码区不得出现 LF 化；普通文本 `\r\n` 不得丢失。

### 3.4 扫描异常与 max_len

- 扫描异常：返回整条原文，不 restyle；
- `max_len`：`len(text) > max_len` → 原样返回（旧行为）。
