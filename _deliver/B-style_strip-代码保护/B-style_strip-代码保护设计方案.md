## 一、目标与首版范围

- 目标：识别并逐字节保护代码内容，不改变 `max_len` 旧行为；
- **首版只承诺 Python 风格**；
- 不支持 JS/C/HTML/Rust 等无围栏代码块；这类语言只保护围栏/行内代码；
- 只改 `style_strip` 与对应测试，不扩展到 `multi_bubble` / `rule_guard`。

## 二、识别设计（四个入口，区间合并去重）

### 2.1 入口 A1a：自包含语句

行首匹配：

`^\s*(import|from|return|yield|raise|assert)\b`

且行内非空；**不是列表/引用/表格**（见 2.8 反例）。

覆盖：`import os`、`from pathlib import Path`、`return result`、`yield item`、`raise ValueError("x")`、`assert x > 0`。

### 2.2 入口 A1b：块起始语句

行首匹配：

`^\s*(async\s+def|def|class|if|elif|else|for|while|try|except|finally|with)\b`

> `lambda` 是表达式，不是块起始语句；`f = lambda x: x` 由 A2 赋值入口覆盖，不放进 A1b。

且满足：

- 行内含 `(`、`=`、`->`、`{`、`[` 之一，**或**下一行以 2+ 空格/Tab 缩进；
- **冒号不单独算代码符号**：`if you have time: 我们聊聊` 只有冒号、下一行不缩进 → 不进入；
- 不是列表/引用/表格。

### 2.3 入口 A2：赋值语句

`^\s*[A-Za-z_]\w*(\s*,\s*[A-Za-z_]\w*)*\s*=\s*`

排除 `==`。覆盖 `x = 1`、`a, b = 1, 2`。

### 2.4 入口 A3：调用语句（函数名后紧跟 `(`）

`^\s*[A-Za-z_][\w.]*\(`

- `print(add(2, 3))`、`foo()` 进入；
- `print (x)`（函数名后有空格）不进入。

### 2.5 入口 A4：纯缩进块（代码特征门槛）

- 连续 ≥2 行以 2+ 空格或 Tab 缩进；
- 块内**至少 2 行**含代码特征：`=`、`(`、`[`、`{`、`->`；
- **`#` 不单独算代码特征**（注释行可能是普通说明）；
- 不是列表/引用/表格；不与围栏/行内代码重叠；
- 从第一行缩进行开始，到第一个非缩进行（或空行后非缩进行）结束；空行保留。

**自然语言反例（不保护）**：

- 连续缩进的普通说明，只有中文/英文句子、无上述特征；
- 连续缩进的注释行（如每行 `# 备注…`，无 `=`/`(` 等）→ 不保护；
- 含两个冒号的说明：`我想说：第一：我们要出发了`（全角/ASCII 冒号均不算特征）；
- `Note: this is a note`。

**空行规则（明确）**：

- 空行**不计入**“连续缩进 ≥2 行”（只统计非空缩进行）；
- 空行**不计入**“代码特征 ≥2 行”；
- 空行后再次缩进：若下一行缩进 ≥ 当前块基准 `base`，区间继续（空行保留在区间内）；若缩进 < `base`，块结束于空行前；
- 连续多个空行按上述规则整体保留或整体结束。

**base 定义（v6 补充）**：

- A4 的 `base` = **候选区间第一条非空缩进行的缩进级别**；
- 空行不改变 `base`；后续行的缩进与此 `base` 比较。

**Tab 计量（v6 补充）**：

- Tab 固定展开为 **4 空格**再比较；
- Tab 与空格混合时：先按 4 展开，再比较缩进级别；
- 同一行内 Tab/空格混用：按展开后的总宽度；
- 首版不拒绝混合缩进，但必须覆盖 Tab-only、空格-only、混合三种边界测试。


### 2.6 base=4 续块（4→8→4）与边界

从起始行开始，`base = indent(i)`：

- 行缩进 > base → 块内（4→8）；
- 行缩进 == base 且匹配 A1a/A1b/A2/A3、闭合行、`else/elif/except/finally` → 块内（8→4，续块）；
- 行缩进 < base → dedent，结束；
- 空行保留；若下一行缩进 < base → 结束于空行前；
- 其它 → 结束。

**base=4 专项**：

```
def f(a):
    if a:                 # base=4
        print(a)          # 8
        return a          # 8
    return 0              # 4，A1a → 续块
    x = 1                 # 4，A2 → 续块
else:                     # 0？不，这里只是示例；实际 else 需同级
```

边界测试：

1. 同级 `return` 后接**普通说明**（非缩进、非 A1a/A2/A3）→ 块结束；
2. 同级赋值 `x = 1` → 续块；
3. `else:` / `finally:` 同级 → 续块（匹配 A1b）；
4. dedent 到 0 → 结束。

### 2.7 行内代码

- 单反引号成对长度 1；双反引号成对长度 2；
- 未闭合保护到行尾，不跨行；
- 不处理反斜杠转义；围栏内不识别行内代码。

### 2.8 A1a 伪自包含反例

以下**不进入** A1a：

- 列表：`- import os`、`1. from x import y`；
- 引用：`> import os`；
- 表格：`| import os |`；
- 普通句子中以这些词开头但带列表/引用/表格前缀的行。

## 三、分段与边界（v6）

### 3.1 正文与行结束符分离

- 用 `splitlines(keepends=True)` 切行，得到 `line`（含 `\n` 或 `\r\n`）；
- 处理时拆出 `body` 与 `ending`：`body = line.rstrip("\r\n")`，`ending = line[len(body):]`；
- 非代码段：只对 `body` 做 restyle，再拼回原 `ending`；
- 代码区间：按原字符串切片（含 `\r\n`），逐字节保留；
- 段间拼接不 `strip`。

### 3.2 混合换行

- 输入可能 LF/CRLF 混排；逐行保留各自 `ending`，不统一；
- 测试：LF 行 + CRLF 行混排，断言每行结束符与输入一致。

### 3.3 边界空行

- 代码区间前后 1/2/3 空行原样保留；
- `squash_blank` 只在非代码段内执行，不跨边界。

### 3.4 CRLF 字节级断言

- 整个最终输出 `out.encode("utf-8") == expected.encode("utf-8")`；
- 代码区不得 LF 化；普通文本 `\r\n` 不得丢失。

### 3.5 扫描异常与 max_len

- 扫描异常：返回整条原文，不 restyle；
- `max_len`：`len(text) > max_len` → 原样返回。
