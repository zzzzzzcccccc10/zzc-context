## 二、W3 WAL 追加与 audit dirfd（J1/J2）

### 2.1 W1 锚点

W1 在 `attempt_created` 记录：
`state_dir{dev,ino}`、`audit_dir{dev,ino}`、`wal{dev,ino,mode=0600,size=0}`、`boot_id`、`attempt_id`；`spawn_begin` 记录 `wal_off`（写后 size）。

### 2.2 W2/W3 重开校验表

| 步骤 | 操作 | 校验 | 失败 |
|---|---|---|---|
| 1 | `open(state_root, O_DIRECTORY\|O_NOFOLLOW\|O_CLOEXEC)` | dev/ino == state_dir 锚点；root:root 0700 | hold/halt |
| 2 | `openat(state_fd, "audit", O_DIRECTORY\|O_NOFOLLOW\|O_CLOEXEC)` | dev/ino == audit_dir 锚点；root:root 0700 | hold/halt |
| 3 | `openat(audit_fd, "attempt-<id>.jsonl", O_RDWR\|O_APPEND\|O_CLOEXEC\|O_NOFOLLOW)`（W2 可 `O_WRONLY`；W3 需 `O_RDWR`） | 无 `O_CREAT`；regular；nlink==1；uid==0；mode 0600；dev/ino == wal 锚点 | hold/halt |
| 4 | fstat size | W2：==spawn_begin.wal_off；W3：≥wal_off，且尾部可解析 | hold/halt |

### 2.3 W3 尾部修复与追加

1. `pread` 末尾 ≤8192B；`rfind(b'\n')` 定位最后完整行；若末尾无换行 → 半行起始 offset。
2. `ftruncate(fd, complete_end)`；`fsync(fd)`；`fstat` 校验 size==complete_end。
3. 读最后完整行：seq/JSON 校验；不合法 → 不写、只读取证、22。
4. 写 `writer_takeover`：`os.write(fd, line+b'\n')`；**O_APPEND 保证追加**；`fsync`；`fstat` size == complete_end+len。
5. 后续 W3 事件同规则；每次写后 size 校验；close 前最后 fsync。

### 2.4 不变量

- W3 打开必须带 `O_APPEND`（禁止仅 O_RDWR 后假定偏移在末尾）；禁止 `lseek` 后无 O_APPEND 的追加假设。
- 截断只允许“尾部半行”，中间行不合法不修复。
- 重开失败：latch 可写 → 22；否则 halt。

## 三、hold / W4 / token（J3/J4/J5）

### 3.1 唯一时序

```text
[supervisor]
hold_request{reason,last_seq} fsync
→ close(release_w)  # 不写 0x52
→ send HOLD_REQ(type=5)  # 立即；失败则 close(P) 继续
→ 收尸：¬exec_begin → SIGKILL launcher + waitpid(T_REAP)
         存在 exec 证据 → waitpid 至 T_CLI_WAIT；仍活 → 记 live_children
→ close(log_fd)  # 最后 fd 动作
→ close(P)
→ _exit(0)
[main]
收到 HOLD_REQ / P EOF / supervisor pidfd POLLIN
→ 停发 ACK/FIN
→ waitpid(supervisor)（T_SUP_EXIT=5s；已见 HOLD_REQ 放宽 T_CLI_WAIT+T_REAP）
→ 超时：close(P) → SIGTERM → 1s → SIGKILL → waitpid(T_REAP)
→ W3 重开（J1/J2）→ writer_takeover fsync
→ 读 WAL 尾判定（hold_request→hold；terminal→不重复写；矛盾→30）
→ token 生成 32B CSPRNG → hold.token 0600 明文+fsync → stderr 一行
→ latch O_EXCL 0600（取 ino）+fsync 文件/目录
→ attempt_hold{latch_ino,reason,live_children,token_sha256,cli_state} fsync
→ close(log_fd) → close(M) → close(L)
→ stdout JSON（22）→ exit 22
```

### 3.2 W4（HALT）

- 进入：latch 连续 3 次写失败 / supervisor 不可杀 / 收养 CLI 长活 / abort 意图但 resolution 写失败。
- 事件：写 `halt{reason}`（尽力）→ epoch 3→4（仅 HALT 事件）→ `run/<id>/HALT` 0600 O_EXCL。
- 行为：持 L/M；每 1s 读 abort.intent；每 5s 重试 latch/收尸；stderr 心跳（不含 token）；SIGTERM 忽略。
- 出口：latch 成功 → 回正常 hold 22；合法 intent + resolution 成功 → 删 latch/HALT/intent → close M/L → 0；SIGKILL → 残留 HALT/latch → 下一事务 23。
- W4 只写 operator_resolution/halt/abort_requested；不写业务事件；不释放 L。

### 3.3 token 崩溃点

| 崩溃点 | 状态 | 恢复 |
|---|---|---|
| latch 前 | 无 latch | 下一事务正常；无 hold 证据 |
| latch 后、hold.token 前 | orphan latch，无 token | recover 无 token → 23 人工；有 abort.intent → 校验 intent + latch，basis=latch |
| hold.token 后、attempt_hold 前 | token 文件 + latch，无 attempt_hold | recover 校验 token/latch → 写 operator_resolution（basis=latch）或 23 |
| attempt_hold 后 | 完整 hold | 正常 recover/abort |
| resolution 后、删 latch 前 | resolution + latch | 下一调用 23；同 token 只清 latch，不重写 |
| account 文件 orphan（token 无 latch） | 无 latch | 清理 token，23 |

## 五、证据状态表（J8）

### 5.1 error pipe

| 类 | 终态/原因 | 判定 | 结论 |
|---|---|---|---|
| NONE | 终态 | 0B+EOF | 无帧（≠成功） |
| FRAME | 终态 | 8B、magic EXC1、errno 1..4095 | exec 失败 |
| SHORT | 错误原因 | 1–7B 后 EOF | 协议错误 → hold |
| OVER | 错误原因 | ≥9B | 重复/外部写 → hold |
| BAD | 错误原因 | 8B 但 magic/errno 非法 | 协议错误 → hold |
| TIMEOUT | 错误原因 | T_EXEC_FRAME=5s 无 EOF | hold，禁 not_sent |
| READ_ERR | 错误原因 | read 其他错误 | hold |

### 5.2 sidecar SC0–SC6

| 态 | 实际情形 | 允许推导 |
|---|---|---|
| SC0 | 文件不存在 | 仅 DR1–DR5；有 cli_spawn_begin → 矛盾 hold |
| SC1 | 0B/仅 created | not_sent 可（¬E） |
| SC2 | 完整前缀（含 created，尾部半行丢弃） | not_sent 可（¬E） |
| SC3 | 自退 terminal（exec_failed/aborted/halt） | aborted∧¬E→not_sent；exec_failed→FAILED；halt→hold |
| SC4 | 损坏（非法 JSON/seq/绑定/非 regular） | hold |
| SC5 | 与 WAL/帧冲突 | hold |
| SC6 | 写者仍活 | hold_live |

### 5.3 N1–N7 与 E/F

- N1 sidecar 态可判（SC0–SC2/SC3-aborted）；N2 绑定一致；N3 收尸+cgroup 空+无未识别子进程；N4 授权态确定；N5 无 exec_begin（P1 构建已验证）；N6 无成功/失败证据（0B 或 unobserved）；N7 not_sent_verified 已持久化。
- E = 合并后 sidecar 事实 `exec_begin` 存在；F = 8B 帧或 sidecar `exec_failed`；`E∧F`→FAILED；`E` 无 F→UNKNOWN；`¬E`+N1–N7→NOT_SENT。
