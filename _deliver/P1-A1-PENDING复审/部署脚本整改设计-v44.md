## 一、进程生命周期（P0-1）

### 1.1 waitpid 五分支

| 返回 | 语义 | 动作 |
|---|---|---|
| `>0`（pid,status） | 回收一个子进程 | 记 pid/status/kind（supervisor/launcher/CLI/其他）；继续 |
| `0` | 有子进程但无状态变化（仍活） | 记“有存活子”；退出 waitpid，转 pidfd/proc 判活；有活体→TERM/KILL |
| `-1, ECHILD` | 无未等待子进程（**非 reparent 未完成**） | 结束 waitpid；对已知 pid 做 pidfd+starttime 判活；无活体→完成；有活体→矛盾 fail-closed |
| `-1, EINTR` | 被信号中断 | 先处理控制信号（abort/halt），立即重试一次；连续二次→其他错误 |
| `-1, 其他` | 参数/环境错误 | fail-closed：hold（WAL 可写）/F/M-HALT（不可写）；连 hold 不可记录→30 |

- 禁止 100ms 重试 ECHILD；禁止把 ECHILD 当死亡证明；非子进程禁止 waitid（ECHILD 不作证明）。
- SIGCHLD 保持 SIG_DFL，禁止 SIG_IGN/handler 吞状态。

### 1.2 身份链与收尸

1. 簿记 `{pid,pstart,boot_id}`（fork/发布时）。
2. `pidfd_open(pid,0)`；`/proc/self/fdinfo/<fd>` 校验 Pid/NSpid（**不是 fstat**）。
3. `/proc/<pid>/stat`（last `)` 切分；state 字段 3、starttime 字段 22）与簿记比对。
4. `poll(pidfd,timeout)`：POLLIN=已终止（未回收）；POLLERR/POLLNVAL→fail-closed；EINTR 重试。
5. `waitpid(-1,WNOHANG)`（仅子进程）回收 status。
6. cgroup/`/proc/children` 仅辅助。

- T_REAP=5s：t0=首次 TERM（或 KILL）；t0+1s KILL；deadline=t0+5s；1s 计入。
- 有活体（WAL 可写）→T-HALT（22，记录 live_children）；有活体且 attempt_hold 不可持久化→hold-live（持 L/M、心跳、SIGKILL→23）；M-HALT 仅 WAL/HALT 均不可写。

### 1.3 observed 三态

| 态 | 条件 | live_children | cli_state | 路径 |
|---|---|---|---|---|
| true | subreaper=1；waitpid 至 ECHILD；已知 pid 全分类（回收或 pidfd+starttime）；无未识别；无矛盾 | 可为 [] 或已知活体 | 可判 | 空→P1；非空→T-HALT |
| partial | 有缺口（children 不可用、缺 pstart、unidentified、pidfd EMFILE、cgroup 无效） | 允许已知活体 | 可 unknown | 禁 P1/not_sent→T-HALT/ F/M-HALT |
| false | 清单无法建立 | []（有活体改 partial 并写入） | unknown | 同上 |

- `observed=false/partial` 不得解释为“无存活子进程”；N3 不成立→不得 not_sent。
- `cli_state∈{not_spawned,exited,signaled,alive,unknown}`；exit code/signal 只在有回收 status 时写，缺失不填 0。

## 二、hold 决策表（P0-2）

| 路径 | 选择条件（互斥） | WAL 事件 | 文件 | L/M | 退出 |
|---|---|---|---|---|---|
| P1 | WAL 可写；sub 死；live=[]；observed=true；N3 可证 | takeover(3)→token→latch→attempt_hold(epoch3) | token+latch；无 HALT | 持→释放 | 22 |
| P2 T-HALT | WAL 可写且（live≠[] 或 observed≠true） | takeover(3)→halt(4)→W4→takeover(4→5)→W4R attempt_hold | HALT+token+latch | 持→释放 | 22 |
| P3 F-HALT | WAL 不可写；HALT 可写 | 无 | HALT(wal_persisted=false)+token+latch | 持→释放 | latch-only 22；token=null→23 |
| P4a M-HALT-latch | WAL/HALT 均不可写；token+latch 成功 | 无 | token+latch（HALT best-effort） | 持→释放 | latch-only 22 |
| P4b M-HALT-无 latch | 同上但 latch 不可写 | 无 | 仅内存 | 持（不释放） | 不退出（心跳）；SIGKILL→23 |
| hold-live | 有活体且 attempt_hold 不可持久化 | 无 | 现场 | 持（不释放） | 心跳；SIGKILL→23 |

- 选择顺序：WAL 不可写→HALT 可写?P3:P4a/b；WAL 可写→observed≠true 或 N3 证不出→P2；live≠[]→P2；否则 P1。
- P2 合并 P5（不可观测子例），事件/文件/退出相同；attempt_hold 记 observed=false/partial、cli_state=unknown。
- 观察：P1 无 halt/W4/W4R；F/M-HALT 永不写 W4/W4R/takeover(5)/attempt_hold。

## 三、W4/W4R/HALT（P1-1）

### 3.1 HALT 字段（闭集）

`{attempt_id, wal_epoch, halt_request_epoch, wal_persisted, halt_seq, holder_pid, holder_pstart, boot_id, reason, created}`

- `wal_persisted=true` ⇒ `halt_seq≥1`、`wal_epoch∈{4,5}`、`halt_request_epoch==wal_epoch`。
- `wal_persisted=false` ⇒ `halt_seq==0`、`wal_epoch∈{1,2,3}`、`halt_request_epoch==4`（禁止 5）。
- `wal_epoch=0` 仅内存初值，不入文件；字段不回退。
- 写序：`wal_persisted=true` 只在对应 WAL 行 fsync+size 成功后写；禁止先 HALT 后补 WAL。
- 创建：`O_WRONLY|O_CREAT|O_EXCL|O_CLOEXEC|O_NOFOLLOW 0600`，单行 JSON ≤4KiB，fsync 文件+目录，fstatat 复核；已存在且 attempt 不同→23。
- T-HALT 允许一次 4→5 原子替换（HALT.tmp→renameat→fsync dir）；F/M 不更新；M-HALT 补写是首次写。
- 删除：仅 WAL attempt_hold 持久后 unlink+fsync(dir)；latch-only 保留。

### 3.2 W4/W4R

- W4（epoch4）：只写 halt/abort_requested/operator_resolution；不写业务事件；不释放 L/M；不自行 exit；心跳不含 token。
- W4R（epoch5）：仅 T-HALT；latch 成功 + halt(4) 已持久 → takeover(4→5)→attempt_hold(epoch5)；W4R 失败→latch-only 22（不重开 WAL、不重写 takeover）。
- 出口：P1/P2→22；P3/P4a→latch-only 22；P4b/hold-live→心跳/SIGKILL→23；abort→resolution→0。

## 四、WAL/存储（P1-2）

### 4.1 flags

| 写者 | flags | O_CREAT | 重开 |
|---|---|---|---|
| W1 | `O_WRONLY|O_CREAT|O_EXCL|O_APPEND|O_CLOEXEC|O_NOFOLLOW` | 唯一 | 创建 |
| W2 | `O_WRONLY|O_APPEND|O_CLOEXEC|O_NOFOLLOW` | 否 | 是 |
| W3/W4 | `O_RDWR|O_APPEND|O_CLOEXEC|O_NOFOLLOW` | 否 | 是（W4 继承 W3） |
| W4R | 继承 W3/W4 fd | — | **否** |

- 全无 O_TRUNC；W2/W3/W4/W4R 无 O_CREAT/O_EXCL；禁止 lseek 定尾/pwrite；单行 ≤256 KiB。

### 4.2 重开与尾修复

- 从 `/` 逐级 openat+fstat（dir/root:root/非组写）；state→audit→WAL 三级 dev-ino；W2 size==wal_off；W3≥wal_off。
- 尾修复：尾向 pread 倍增窗口至 256 KiB；`complete_end<wal_off`/超限→NV 不截断；只读校验最后行；裁决不可写→关闭不写；可写才 ftruncate+fsync+fstat；写 takeover/后续事件：写前 size==expected、写后==expected+len、n==len；短写不补、停写。
- 关闭前 `fstatat(audit_fd, basename, &st, AT_SYMLINK_NOFOLLOW)`：regular/nlink1/uid0/gid0/0600/dev-ino 一致；失败 STOP/NW（hold 已持久→22；否则 30），禁止补救写。

## 五、error pipe（K4 + FRAME EOF）

- 创建/端点/W2 读/exec_frame 继承 v42；`T_EXEC_FRAME=5s`。
- 读到 8B 后继续 poll/read 确认 EOF：8B+EOF→FRAME（`exec_frame{frame,eof:true}`→F）；8B+额外字节→OVER/BAD→hold；1–7B+EOF→SHORT→hold；≥9B→OVER→hold；magic/errno 非法→BAD→hold；5s 无 EOF→TIMEOUT→hold；read 错误→READ_ERR→hold。
- 仅 launcher 写 8B（短写不重试→72）；仅 W2 读并写 exec_frame+fsync；W3 不重读；迟到帧不改判。
