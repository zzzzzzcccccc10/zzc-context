## 七、FC-01 断言（T3-01/T3-02）

- FC-A：exit 0 + 单行 JSON。
- FC-B：gate_authorized 唯一且先于 release。
- FC-C：release 恰一次三重（WAL 事件 + sidecar cli_release_received + canary read 计数；T2 另加发送计数）。
- FC-D：sidecar_merged 唯一且内联关键事实。
- FC-E：exec_observed(success) + CANARY_EXEC 唯一。
- FC-F：start_result(exit_0,command_sent=yes) + resolution 最后。
- FC-G：快照 A `{0,1,2,sidecar_w,error_ew}`，CLOEXEC 精确。
- FC-H：快照 B `{0,1,2}`，无 L/M/socket，1/2 身份一致。
- FC-I：锁/进程收束，无残留。
- FC-J：gate_mono < release_mono < exec_mono。
- FC-K：零残留。
- FC-01a 失败 → 依赖放行链的 T2/T3 负例 UNDECIDABLE；T0/T1/T4 可重开批次。FC-01b 可 A2-R 单独授权；未跑 running/match=UNDECIDABLE。

## 九、判定规则

- 每例唯一结果 token + 精确退出码；多结果/未定义 token 不得入库。
- 不可判定（U1–U7）一律计不通过；watchdog 触发=FAIL。
- 每批通过 = 全部必测 PASS + 无 U + 清理证明 + FC 传播满足。
- 生产包不得含测试/变异资产；变异仅在 A2/A0 测试构建。
