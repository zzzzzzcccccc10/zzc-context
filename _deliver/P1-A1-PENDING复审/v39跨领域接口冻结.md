## 二、启动链接口（冻结摘要）

- **安装树**：`/opt/astrbot-deploy/{bin/astrbot-deploy(0755,#!/bin/sh),lib/deploy.py(0644),lib/SHA256SUMS(0644),lib/VERSION(0644)}`；祖先链 root:root、非 symlink、无组/世界写；dirfd+dev/ino 锚点。
- **状态树**：`/var/lib/astrbot-deploy/{lock(0600),audit/audit.jsonl(0600),run/(0700),latch/(0700),probe/(0700)}`。
- **wrapper**：≤40 行，仅 `stat/readlink/sha256sum` 白名单，校验树/SHA/解释器后 `exec /usr/bin/python3 -I -S -B .../deploy.py "$@"`；不 fork。
- **单文件约束**：仅标准库；bootstrap 先断 flags（`isolated/no_site/dont_write_bytecode/ignore_environment`）→ 导入标准库（失败 exit 10）→ `umask(077)`、`chdir("/")`、TZ/LC 设置 → main；末尾 `os._exit(rc)`。
- **selfcheck S-01…S-16**：flags、Python/内核/API、路径、安装树/SHA/VERSION、sys.path 卫生（不依赖 `sys.path[0]`）、euid、SIGPIPE、runtime 设置、状态根、docker 文件/`_ping`、cgroup 探针、写探针、lock、prctl。
- **exit 10 域**：wrapper 预检 + helper 自检 + bootstrap 失败；pre-`__main__` 解释器失败明确出契约（126/127/信号）。
- **stdout**：恰一行 JSON `{v,exit,outcome,attempt_id,reason}` + 扩展；`outcome` 枚举见 A §6.4。
- **安装/升级**：tarball 带外 SHA；目录换名原子；失败回滚 40/41；latch/未裁决 hold 时拒绝升级（11）。

## 三、FD 接口（冻结摘要）

- **矩阵**：main M0/M1、supervisor S1/S2、launcher L0/L1a/L1、CLI C1；每 FD 的创建/关闭/CLOEXEC/身份。
- **fork 瞬间**：main 9 fd、supervisor 12 fd；“库存−白名单”关闭 + 精确断言；失败 `_exit(71)`。
- **execve 前**：`{0,1,2,L,sidecar_w,error_ew}`（快照 A，launcher 自证，`fcntl(F_GETFD)` 精确）；**exec 成功后**：`{0,1,2,L}`（快照 B，canary 自证/生产 `/proc/<pid>/fd` 佐证）；CLOEXEC 除 L 外全真；L 仅 launcher 副本清标志。
- **0/1/2**：main 规范化 inheritable；1/2 重定向到 `run/<id>/cli.log` 或 `/dev/null`（D11）。
- **两次 fork 失败**：main 继续写 `spawn_failure`/not_sent/resolution（fork1 失败）；supervisor 写 `cli_spawn_failure`（fork2 失败）；`spawned` 只由 supervisor 写。
- **写者**：W1 main（spawn_begin 前）；W2 supervisor（spawned 起）；W3 main 恢复写者（takeover 后）；W4 holder；Seq 每次 append 独立 flock。
- **hold 修正（D12）**：holder 写 latch 后释放 L 退出 22；23 由下一调用返回；`hold_and_halt` 仅 latch 写不进。
- **锁**：L 全局、M attempt、Seq 追加；关闭序：terminal fsync → resolution fsync → 删 unresolved → close log/M → 最后 L；锁文件 dev/ino 锚定、O_NOFOLLOW。
- **error pipe**：唯一写端 launcher；fork2 后 supervisor 关自己副本；只接受 0B EOF 或 8B `EXC1+errno`；1–7B/>8B hold；0B EOF ≠ 成功。
- **sidecar_w**：仅 launcher；main/supervisor 关闭副本；`sidecar_merged` 内联 `snapshot_sha`/fds。

## 四、状态与重放接口（冻结摘要）

- **唯一顺序**：`... ack_ok→fin_ok→eof_observed → cgroup_migrated(gate=closed) → gate_authorized → release_byte → exec_observed/cli_reaped → sidecar_merged → terminal → resolution`；相邻性写死。
- **gate 载荷**：challenge_sha、ack/fin/eof seq、cli pid/starttime、pidfd fdinfo、cgroup 锚点/readback、各判据结果。
- **evidence 分表**（8 类）：early/ack/cli_migrate(**closed**)/release(authorized,failed)/cli_abort_before_exec(成对)/execve_failure(released,written)/exec_unconfirmed(released,written,unknown)/evidence_write_failed(hold)。
- **T-NOT-SENT**：N1–N6（sidecar 已合并、身份、已回收+cgroup 空+无未识别子进程、无 exec_begin、error pipe 0B、无 success/failure）。
- **T-EXEC-FAILED/SUCCESS/UNKNOWN**：FAILED > SUCCESS > NOT-SENT > UNKNOWN；冲突 hold；SUCCESS 方法（exit0/ptrace/proc_exe，后者需实验）；UNKNOWN 由 evidence+start_result 承载。
- **launcher 退出码映射**：70 gate_closed、71 协议/fd、72 持久化、74 快照、79 内部兜底（hold）、127 execve 失败。
- **重放阶梯**：operator_resolution > resolution > start_result > start_not_sent > attempt_hold（非终态）> 可证派生（DR1–DR12，含 evidence-only/授权后失败）> hold > invalid > unknown；采用前校验（唯一性/authority_seq/顺序/写者/not_sent 复核/unknown 成对）。
- **operator_resolution**：必须有 attempt_hold + token/latch 校验 + 阶段限制（未 gate 可 not_sent；已 release 无 exec 证据只能 unknown）。
- **sidecar 状态**：ok/empty 可合并；截断/冲突/绑定不符 → hold；空 sidecar 仅 launcher_terminal+reaped 合法。

## 六、跨领域裁定（冲突闭合）

1. **`-I` 与 zipapp**：采用单文件（D1）；删除 `sys.path[0]==pyz` 断言；正确性不依赖 sys.path。
2. **hold 22/23**：采用 latch+22/23（D12），替换 v38“活体 hold 不退出”；recover 只读、不抢锁；`hold_and_halt` 仅 latch 写不进。
3. **launcher 兜底码**：127 仅 execve 失败（带 errno 证据）；79 内部兜底；与 C 的 D5 一致。
4. **CLI fd 1/2**：重定向到 run 日志/ /dev/null（D11）；CLI 集合 `{0,1,2,L}` 中 1/2 的 dev-ino 为日志/ null，快照 B 验证。
5. **迁移前置**（D6）：v38 的“迁移后置”全部删除；矩阵 F05/P11 同步。
6. **时间预算**：共享绝对 deadline（D13）；阶段 cap 不重置；watchdog 触发=FAIL。
7. **E16 归属**：归 A0（安装/升级与启动实测同环境）；不新增 A3。
8. **真实 docker**：FC-R 为可选 scope；未跑 FC-R 时，“真实 running/match 来源”结论标 UNDECIDABLE，不冒充 seam 结论。
