## 一、hold 状态机（唯一）

### 1.1 固定判定顺序

0. W3 重开+尾修复；spawn_closed 计算；有界收尸（waitpid 五分支）。
1. 有活体/observed≠true：WAL 可写且 takeover(3)+halt(4) 成功→P2（22）；否则 P4b hold-live（持 L/M、心跳 1s、SIGKILL→signal9；next run 23）；P1/P3/P4a 禁止。
2. 无活体 observed=true：WAL 可写→P1（attempt_hold 成功）或 P1-H（attempt_hold 失败，22 basis=latch）；WAL 不可用→P3（token+latch+HALT，22）或 P3a（HALT 失败，22）或 P4b（latch 失败）；WAL/HALT 均不可用→P4a（latch 成功，22）或 P4b（latch 失败）。

### 1.2 路径表

| 路径 | 条件 | WAL 事件 | 文件 | L/M | 退出 | basis |
|---|---|---|---|---|---|---|
| P1 | 无活体+observed+WAL 可写+全成功 | takeover(3)→token→latch→attempt_hold(3) | token+latch | 持→放 | 22 | attempt_hold |
| P1-H | P1 但 attempt_hold 失败 | takeover(3) | token+latch | 持→放 | 22 | latch |
| P2 | 有活体/不可观测+WAL 可写+takeover(3)+halt(4) | takeover(3)→halt(4)→W4→takeover(4→5)→W4R attempt_hold(5) | HALT+token+latch | 持→放 | 22 | attempt_hold；W4R 失败→§二 |
| P3 | 无活体+observed+WAL 不可用+latch 成功+HALT 成功 | 无 | HALT(false)+token+latch | 持→放 | 22 | latch |
| P3a | P3 但 HALT 失败 | 无 | token+latch | 持→放 | 22 | latch |
| P4a | 无活体+observed+WAL/HALT 不可用+latch 成功 | 无 | token+latch | 持→放 | 22 | latch |
| P4b | 有活体/不可观测且 P2 不可行；或 latch 不可持久 | 无新增（已写保留） | token+HALT(false)（可写时） | 持（不放） | 无受控退出；心跳；SIGKILL→signal9；next 23 | 23 人工 |

- latch 成功=create+write+fsync file+fsync dir+目录项复核；失败→P4b。
- hold-live 的 SIGKILL 无退出码；23 是下一次 run 的拒绝码。
- P2 的 takeover/halt 失败→P4b；P2 的 attempt_hold 失败→§二。

## 二、W4R 失败（S1/S2/S3）与 resolution

### 2.1 子状态

| 子态 | WAL 末完整行 | 半行 | HALT | 首次退出 | basis |
|---|---|---|---|---|---|
| S1 | halt(4) q epoch4 | 无 | (4,4,true,q) | 重新观测：活体/不可观测→hold-live；否则 22 | latch |
| S2a | takeover(4→5) q+1 epoch5；无 attempt_hold | 无 | (5,5,true,q) | 同上 | latch |
| S2b | takeover5 已持久；HALT 仍 4/4 | 无 | (4,4,true,q) | 同上 | latch |
| S3a | halt(4)；takeover5 半行 | 有 | (4,4,true,q) | 首次不截断；下次 recover 尾修复→S1 | latch |
| S3b | takeover5 完整写但 fsync EIO（恢复时同 S2） | 无 | (4,4,true,q) | 按 S2 | latch |
| S4 | attempt_hold 已持久 | 无 | (5,5,true,q) | 崩溃无退出；错误返回 22 | attempt_hold |

- 恢复顺序：全前缀重放→attempt_hold?→S4；takeover5?→S2a/S2b；halt(4)?→S1；半行→S3a。
- 不补 takeover5/attempt_hold；首次不截断；recover 只截尾半行。
- **resolution 文件**：`run/<id>/resolution.json` 0600 O_EXCL 单行 ≤4KiB fsync file+dir；字段 `{v,attempt_id,basis,authority_seq,anchor,token_sha256,observed,spawn_state,resolved_at}`；WAL 可写且末 epoch=4 可双写 operator_resolution；末 epoch=5 只写文件；`anchor∈{wal,none}`，`authority_seq=不含本条的最后持久 seq`，0=none；`resolved` 派生（文件或 WAL 事件存在），不落 HALT。
- recover 前置：A 域链证明 launcher/CLI/live_children 全死；任一活/不可确认→23/30 零 WAL 写；observed=partial∧spawn_state=open→23 人工。

## 三、PID 发布与崩溃窗口

### 3.1 权威

| 对象 | 来源 | 持久化 |
|---|---|---|
| supervisor | main fork1 返回+内存；W1 不写 | recover 取 `spawned` 封套 pid/pstart/boot_id；无→23 |
| launcher/CLI | W2 `cli_spawned{cli_pid,cli_pstart,boot_id}`（fork2 后、gate/release 前 fsync） | WAL；main W3 后读取 |

- 正常启动：`spawned→cli_spawn_begin→fork2→cli_spawned→metadata_published→pidfd_sent→…`。
- `cli_spawn_begin` 无 pid；`cli_spawned` 唯一发布；封套 pid 是 writer。

### 3.2 崩溃窗口（begin 有、cli_spawned 无/无效/半行）

1. spawn_closed=false；observed=partial（无条件）；cli_state=unknown；禁 not_spawned。
2. 有界 drain（T_REAP）：>0 未知 pid→unidentified_reaped；0→unidentified_live；ECHILD→停；不向未知 pid 发信号。
3. WAL 可写且 takeover(3)+halt(4) 成功→P2（22）；否则 P4b hold-live；禁 P1/P3/P4a/not_sent。
4. attempt_hold 增 `spawn_state:"open"`、`cli_pid:null`、`cli_pstart:null`、`reason:"cli_spawn_unpublished"`。
5. 恢复：observed=partial∧spawn_state=open→23 人工，零 WAL 写。

### 3.3 observed 与 pidfd

- observed=true 合取：subreaper=1；spawn_closed（spawned 存在；begin⇒恰一条合法 cli_spawned）；已知 pid 全分类；无未识别；无矛盾；drain 至 ECHILD 或已知活体已分类。
- partial：spawn_closed=false、pstart 缺失、pidfd EMFILE、/proc 不可读、unidentified、cgroup 无效等；false：清单无法建立。
- pidfd：POLLIN 唯一可依赖；POLLHUP 仅≥6.9 辅助；POLLERR 现行不产生（出现 fail-closed）；POLLNVAL=fd 非法（30）；EINTR 重试；禁 SA_NOCLDWAIT/SIG_IGN；SIGCHLD SIG_DFL；main 单线程；subreaper 不继承。
- waitpid：>0 回收（未知→unidentified）；0=有活子；ECHILD=无未等待子（不作死亡证明）；EINTR 重试一次；其他→hold。
- 非子进程禁 waitid；发信号只用 pidfd_send_signal；收养 CLI 用 waitid(P_PIDFD)。

## 四、WAL/文件

- flags：W1 `O_WRONLY|O_CREAT|O_EXCL|O_APPEND|O_CLOEXEC|O_NOFOLLOW`；W2 `O_WRONLY|O_APPEND`；W3/W4 `O_RDWR|O_APPEND`；W4R 继承；全无 O_TRUNC。
- 尾修复：全前缀重放校验；窗口 256KiB；单行含 `\n`≤256KiB；`complete_end<wal_off`→NV；截断后 fstat/expected 重算；短写不补、停写；fsync EIO→停写、不把重试成功当持久证据。
- fstatat(audit_fd,basename,AT_SYMLINK_NOFOLLOW)；regular/nlink1/uid0/gid0/0600/dev-ino；失败 STOP/NW。
- latch/token/HALT/resolution 均单行、0600、O_EXCL、fsync 文件+目录、目录项复核；HALT 闭集 10 字段，resolved 不落盘。

## 五、error pipe / sidecar / NOT-SENT

- FRAME 必须 8B+EOF；8B+extra→OVER/BAD；8B+TIMEOUT→hold；1–7B→SHORT；0B→NONE。
