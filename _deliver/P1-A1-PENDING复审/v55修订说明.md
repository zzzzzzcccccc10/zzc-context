## 一、P1-1 audit fsync 状态唯一（方案 B）

- 写入时：`fsync(file)`/`fsync(dir)` EIO→当次 `audit_record=unknown`（不写文件，仅 stdout `audit_record_write_failed`）。
- 重启后：重新验证 audit 文件（单行/JSON/dev-ino/attempt_id/resolution_sha256 一致）**且** WAL epoch4 `operator_resolution` 完整一致→`present`；否则 `unknown`。
- 优先级：重启后验证优先于“写入时 EIO”；写入时 EIO 不是永久 unknown 标签。
- m3a 拆两向量：m3a1（fsync file EIO，重启+WAL epoch4 一致→present，0）；m3a2（fsync file EIO，重启无 WAL epoch4→unknown，0）。m3b（fsync dir EIO，重启无交叉→unknown，0）。
- 每向量唯一 `(outcome,reason,X)`；不得在一个 ID 内同时写 unknown 和 present。

## 三、P1-3 dev-ino 逐组件打开

```
state_root_fd = open("/var/lib/astrbot-deploy", O_DIRECTORY|O_NOFOLLOW|O_CLOEXEC)
run_fd = openat(state_root_fd, "run", O_DIRECTORY|O_NOFOLLOW|O_CLOEXEC) + fstat 锚点
attempt_fd = openat(run_fd, id, O_DIRECTORY|O_NOFOLLOW|O_CLOEXEC) + fstat 锚点
audit_fd = openat(attempt_fd, "audit", O_DIRECTORY|O_NOFOLLOW|O_CLOEXEC) + fstat 锚点
WAL = openat(audit_fd, wal_basename, O_RDONLY|O_NOFOLLOW|O_CLOEXEC) + fstat
```

- 每级 fstat（dev/ino/mode/uid/nlink）与 attempt_created 锚点比对；后续操作只用已验证 dirfd + 单段 basename；禁止用含 `/` 的字符串路径调用 fstatat。
- 对象/父 FD 映射：state_root 父=`/`（或安装根）；run 父=state_root_fd；attempt 父=run_fd；audit 父=attempt_fd；WAL 父=audit_fd。
- 中间组件（run/attempt/audit）均 O_NOFOLLOW，防中间符号链接。
- q1–q4 覆盖 openat/fstat/fstatat 三类失败：openat ELOOP/EACCES、fstat 锚点不符、fstatat dev-ino 不符。
