## 二、Lead 二次裁定（关键冲突）

1. **hold 顺序**：固定“先活体/observed → WAL 可写 → takeover/halt → token/latch → attempt_hold”；latch 失败→P4b；P3 需 latch；P3 HALT 失败→P3a；P1 attempt_hold 失败→P1-H。
2. **W4R 失败**：S1/S2a/S2b/S3a/S3b/S4；首次退出先重新观测（有活体→hold-live；无活体→22）；recover basis=latch（S4=attempt_hold）。
3. **resolution 载体**：新增 `run/<id>/resolution.json`（0600 O_EXCL 单行 fsync file+dir）；WAL 可写且末 epoch=4 可双写 operator_resolution；末 epoch=5 只写文件；resolved 为派生谓词，不落 HALT；anchor 为字段（wal|none），authority_seq=不含本条的最后持久 seq，0=none。
4. **PID**：supervisor= fork1 返回/内存，W1 不写，recover 取 spawned 封套；launcher/CLI=`cli_spawned{cli_pid,cli_pstart,boot_id}`（fork2 后 fsync）；正常启动时序补该事件。
5. **崩溃窗口**：begin∧¬spawned→observed=partial、spawn_state=open、cli_state=unknown；只 P2 或 hold-live；禁 P1/P3/P4a/not_sent；attempt_hold 增 spawn_state/cli_pid/cli_pstart/reason=cli_spawn_unpublished；恢复 23 人工。
6. **observed=true**：加 spawn_closed 合取项；pidfd 事件语义按 A；禁 SA_NOCLDWAIT/SIG_IGN；单线程；subreaper 不继承。
7. **时间**：126s 从完整合法帧+EOF 起；5s 从 EOF 无帧起；完整帧无 EOF→1s 协议违规；P 开无帧无 EOF→5s 协议违规；watchdog 180s（halt-live 例外）。
8. **A0 门禁**：U-01/U-02 未冻结→A0 全单元 BLOCKED；T0B-03/05/16 另需 F-SEAL。
9. **计数**：103 族/113 子例（新增 T2-21、T3-22；不删旧）；F-KILL 7→8。
10. **latch schema**：`{v,attempt_id,token_sha256,reason,created,boot_id,holder_pid,holder_pstart}`（0600 O_EXCL 单行 fsync+dir）。token/intent/resolution schema 按 v45核心裁定 §二/§三。
11. **reason 闭集**：新增 `cli_spawn_unpublished`、`wal_durability_unconfirmed`、`recover_identity_unconfirmed`；其余继承。
12. **operator_resolution 双身份**：文件为清理依据，WAL 事件为审计（可写时）；二者都唯一；同 token 只清理。
