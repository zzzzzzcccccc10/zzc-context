## 二、Lead 二次裁定（闭合 U 项）

1. **waitpid（P0-1）**：正数=回收；0=有存活子；ECHILD=无未等待子进程（不作“reparent 未完成”）；EINTR 重试一次；其他 errno→hold（WAL 可写）/F/M-HALT（不可写）；连续二次 EINTR→其他错误。
2. **身份链**：pidfd_open→`/proc/self/fdinfo/<fd>`（不是 fstat）→`/proc/<pid>/stat` starttime（last `)` 切分）→poll→waitpid→cgroup/proc 辅助；非子进程禁止 waitid；`/proc/children` 仅辅助。
3. **observed**：true 需 subreaper 回读=1、waitpid 至 ECHILD、已知 pid 全分类（回收或 pidfd+starttime）、无未识别、证据无矛盾；partial/false 不得走 P1、不得 not_sent；有活体不得写 false；`cli_state` 五值。
4. **T_REAP 超时**：WAL 可写且有活体→T-HALT（22，记录 live_children），不是 M-HALT/23；M-HALT 仅 WAL/HALT 均不可写。
5. **hold-live**：有活体且 attempt_hold 不可持久化→持 L/M 心跳、SIGKILL→23；不得 latch-only 22（U-04 采纳）。
6. **hold 决策表（P0-2）**：采纳 C 的 P1–P5；P2 合并 P5（“WAL 可写且（有活体∨observed≠true）”），P5 作 P2 子例；observed=false 禁 P1。
7. **W4/W4R**：仅 T-HALT（P2）；P1 无 halt；F/M-HALT 永不写 W4/W4R/takeover(5)/attempt_hold。
8. **HALT 字段（P1-1）**：`wal_epoch/halt_request_epoch/wal_persisted/halt_seq`；`wal_persisted=true⇒halt_seq≥1、wal_epoch∈{4,5}、request==wal_epoch`；false⇒seq=0、wal_epoch∈{1,2,3}、request=4（禁止 5）；不得先 HALT 后补 WAL；T-HALT 允许一次 4→5 原子替换；F/M 不更新；M-HALT latch 成功→latch-only 22（补写 HALT best-effort），失败→心跳 S/KILL→23。
9. **P-HALT**：不写 WAL、不写 HALT；证死后转 T；WAL 打开即失败转 F（U-B3 采纳）。
10. **fstatat（P1-2）**：`fstatat(audit_fd, basename, &st, AT_SYMLINK_NOFOLLOW)`；校验 regular/nlink1/uid0/gid0/0600/dev-ino；失败 STOP/NW（hold 已持久→22；否则 30），禁止补救写。
11. **WAL flags**：W1 `O_WRONLY|O_CREAT|O_EXCL|O_APPEND|O_CLOEXEC|O_NOFOLLOW`；W2 `O_WRONLY|O_APPEND`；W3/W4 `O_RDWR|O_APPEND`；W4R 继承 W3 fd，不重开；全无 O_TRUNC；W2/W3/W4/W4R 无 O_CREAT。
12. **尾修复**：256 KiB 窗口；`complete_end<wal_off`→NV 不截断；短写不补、停写；写前后 size 校验；单行上限 256 KiB 入冻结（U-B6 采纳）。
13. **A0 门禁（P1-3）**：U-01/U-02 未冻结→A0 全单元 + F-SEAL + T0B-03/05/16 + E16a–f + D0–D9 + installer 直调 BLOCKED；两阶段解锁；单独 A0 授权不能跳过；BLOCKED 不计分、不填 0/N/A。
14. **T2-02a（P1-4）**：W2 `hold_request` 行 fsync 首次 EIO、仅重试 fsync 一次成功、行不重写、seq 不跳；终态 `hold_request→takeover(2→3)→attempt_hold`；无 halt/takeover5/terminal；token/latch/HOLD 帧/exit 22 全断言。
15. **T2-02b**：WAL+latch 持续 EIO、HALT/stdout 正常；P4 前置放宽为“WAL 不可写 + latch 不可落盘；HALT 可写则写 HALT(wal_persisted=false)”；halt-live、无 exit、SIGTERM 忽略、SIGKILL 收尾。
16. **T3-18（P1-5）**：A/B/C 独立快照、逐向量唯一、三向量零 WAL 写；A=23（latch 后/attempt_hold 前杀 main）；B=23（SIGSTOP supervisor+杀 main，pidfd/starttime 匹配）；C=30（boot_id 不符；禁用 pid 不存在/starttime 不符）。
17. **orphan token（P1-6）**：--confirm 64hex 严格；token 文件含 boot_id/token_sha256；无 latch 时身份=attempt_id+holder+boot_id+nonce+WAL/HALT 交叉；authority_seq=最近持久 seq 或 0；abort.intent 含 attempt_id/token_sha256/nonce/holder/boot_id；resolution 含 token_sha256；同 token 幂等 0、异 token 23；清理顺序 resolution→intent→HALT→token→latch。
18. **时间（P1-7）**：`T_CLI_WAIT=125s` 从 release_byte 成功起；`T_SUP_EXIT_FRAMED=126s` 从收齐合法 HOLD_REQ 帧（含 EOF）起，含 125s；P EOF 无帧→`T_SUP_EXIT=5s`；`T_REAP=5s` 从 TERM/KILL 起（1s 计入）；`T_EXEC_FRAME=5s` 从 release_byte；`T_ABORT_WAIT=5s`；watchdog 独立 180s、触发=FAIL（02b/04a halt-live 例外）；不得叠加。
19. **NOT-SENT**：n1n7（¬E+N1–N7，N3 observed=true）；frame_proven（E 持久 + F=8B+EOF；免 N5/N6，仍需 N1–N4+N7）；FRAME 三态（EOF/OVER/TIMEOUT）。
20. **outcome**：recover 成功复用 `success`→0（reason=recovered），不新增枚举；T1-21 11 枚举不变。
21. **计数**：101 族/105 子例不变；T3-18 三向量不拆；T2-02a/b；T4-04a/b。
