## 二、Lead 二次裁定（闭合 U 项）

1. **token→latch**（A-05）：接受；J3 摘要“latch→token”作废；J5“latch 后 token 前”降级为“token 写失败后的双故障行”。
2. **W4R/epoch5**（A-04）：接受；W4 只写 halt/abort_requested/operator_resolution；latch 成功后 `writer_takeover(prev_epoch=4→5)` → W4R 写 attempt_hold → 22。
3. **四种 HALT 形态**（A-03）：T-HALT/P-HALT/F-HALT/M-HALT；P-HALT 在 supervisor 死亡证明前禁写 WAL；halt(4) 必须落盘（M-HALT 除外，以 HALT 文件/内存态）。
4. **hold_request 后 supervisor 零 WAL 写**（A-10）：接受；attempt_hold.cli_state 由 main 观测/推断，不得伪造 exit。
5. **orphan token 保留 + 23**（A-13）：接受；不清理 token；resolution 后按 A-14 顺序清理。
6. **W4 无 token 的 abort**：保持 fail-closed（只能 SIGKILL+23）；不新增 override 通道（U-A3 reject）；文档化人工清理程序。
7. **时间常量**（A-12 勘误）：`T_SUP_EXIT=5s`、`T_SUP_EXIT_FRAMED=126s`、`T_CLI_WAIT=125s`（共享绝对 deadline）、`T_REAP=5s`、`T_EXEC_FRAME=5s`、`T_ABORT_WAIT=5s`；E12 校准不改 cap。
8. **WAL 追加/重开**（B）：接受 —— audit dirfd 从 `/` 逐级 openat+fstat（state→audit→WAL 三级 dev-ino）；W2 `O_WRONLY|O_APPEND|O_CLOEXEC|O_NOFOLLOW`、W3 `O_RDWR|O_APPEND|...`、均无 O_CREAT/O_TRUNC；尾窗口倍增（≤256KiB）；“只读定位→最后行校验→裁决→（可写才）ftruncate+fsync→takeover+fsync”；写前后 size 校验；关闭前 fstatat 复核。
9. **D0–D9**（C）：接受 15 子状态表（D0a/D0b/D1/D1b/D2/D3/D4/D5/D5x/D6/D6b/D7/D7b/D8/D9）；D4=0 提交完成、D5/D6/D6b/D7/D7b/D8=40、D2/D3/D9=30、D5x=41；恢复再崩溃重入表；E16e S1–S9 映射。
10. **error pipe**：接受七态两层（NONE/FRAME=终态；SHORT/OVER/BAD/TIMEOUT/READ_ERR=错误原因→HELD）；仅 launcher 写、仅 W2 读并写 `exec_frame`+fsync；W3 不可重读；`T_EXEC_FRAME=5s`；迟到帧不改判。
11. **sidecar**：接受 SC0–SC6 一一映射（absent/empty/prefix/terminal/corrupt/conflict/live）；合并后以 WAL inline 为唯一权威；SC 判定优先级；与 WAL/帧矛盾提升 SC5。
12. **N1–N7/E/F**：接受；E=合并后 sidecar 的 `exec_begin`；F=8B 帧或 sidecar `exec_failed`；`E∧F`→FAILED；`E` 无 F→UNKNOWN；`¬E`+N1–N7→NOT_SENT。
13. **FAILED→not_sent(cli_exec_failed) 20**（U-C1）：接受；执行层 FAILED 与 outcome not_sent 分层；T3-09/10/11 保持。
14. **矩阵口径**：101 族/105 子例（T2-02a/b 使 T2=23、T4=9）；T2 02a 22 / 02b N/A(halt-live)；T4-04a N/A；T3-02 未授权 BLOCKED/N/A；T1-13 四向量唯一；evidence 11 行落盘 + evidence_write_failed=hold reason；执行器 `$H/run --contract v1 --case`。
15. **FC-L**（U-07）：接受新增快照 0 断言，T3-01/02 期望改 FC-A..L。
16. **D7b**（U-03）：首装 canonical ABSENT、retire/stage 残留、未安装、40。

## 四、跨领域接口冻结（供完整设计）

- **写权**：W1 main/1 → W2 supervisor/2（spawned 起）→ W3 main|recover/3（takeover）→ W4 main/4（halt）→ W4R main/5（takeover halt_released）。
- **hold**：supervisor hold_request fsync → close release_w → 立即 HOLD_REQ → 收尸 → close log_fd → close P → 退出；main 收帧/EOF → waitpid → W3 重开 → takeover → token→hold.token→stderr→latch→attempt_hold → close log_fd → close M → close L → 22。
- **WAL**：W1 建 WAL + fsync(audit_fd) 锚点；W2/W3 从 `/` 逐级 openat 重开（state→audit→WAL 三级 dev-ino）；W3 O_APPEND + 尾修复；写前后 size 校验；关闭前 fstatat 复核。
- **死亡证明**：pidfd POLLIN/ESRCH/proc 不存在/starttime 不符 = 已退出；存活→23；无法确认→30；waitid ECHILD 不作证明。
- **安装**：D0–D9 15 子状态 + S1–S9 映射 + 恢复再崩溃重入；journal 最后删。
- **证据**：error pipe 七态两层；SC0–SC6；N1–N7；E/F；evidence 11 行 + evidence_write_failed hold reason。
