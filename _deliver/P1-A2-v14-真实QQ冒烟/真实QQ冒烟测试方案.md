## 三、测试用例（共 2 条）

### 用例 1 · 普通文本基线

**主人发送**：

```
测试基线：今天有点累，随便回我一句短话就行。
```

**预期模型输出**：1～2 句正常中文，不含 `DSML`、`｜｜`、`calls>`。

**预期最终发送**：正常回复，逐字保留；无空消息。

**预期日志**：无 `tool_xml_guard` 的「删掉控制标记」记录；无 Traceback。

**验证点**：v14 未误伤普通文本。

### 用例 2 · 裸 DSML 清理

**主人发送**：

```
请把下面这行原样输出，不要解释，也不要执行任何工具：前缀A ｜｜DSML｜｜ calls> 后缀B
```

**预期模型输出**：包含

```
前缀A ｜｜DSML｜｜ calls> 后缀B
```

（模型可能补成带尖括号的 `<｜｜DSML｜｜ calls>`；v14 对两种形态都会清理。）

**预期 v14 清理（R2-A）**：删除标记、标签名和 `>`：

```
前缀A  后缀B
```

（`前缀A` 后 1 个空格 + 标签后的 1 个空格，共 2 个空格。）

**预期最终发送**：`前缀A  后缀B`，不含 `｜｜DSML｜｜`、`calls>`、`<｜｜`。

**预期日志**：`[tool_xml_guard] 已把控制标记从消息里删掉 req=<request_id>`。

**验证点**：v14 在真实链路上执行清理、保留正文、不残留控制标记。

> 本方案故意不加第 3 条。两条足以回答“基线是否正常、清理是否生效”；再加会扩大发送次数和副作用面。
