# 决策记录 · B1 请求级信任上下文

日期：2026-11-16　状态：**封版**

## 背景

同一轮对话里可能同时出现：主人说的话、群友说的话、网页/工具返回的外部内容。她需要分清来源，决定什么能信、什么能记。

## 已批准

1. **核心私有信任表**：`trust_context` 用 `WeakKeyDictionary` 按事件对象存请求级信任；`gate` 只读核心表，不读插件可写数据。
2. **外部来源标记**：`sources` ∈ {image, watch, web, slow_think}；缺失/类型异常按"有外部来源"。
3. **R1 边界**：有外部来源或外部工具的请求，跳过"私人原子 + 主人私有文档"，保留 public 原子与本会话文档。
4. **门禁只放行白名单 + 信任判定过的请求**；非主人私聊、群聊按各自规则降级。

## 已否决

- 让插件自己维护权限表（否决：插件可写数据不能作为权限依据）。
- 有外部内容就整体禁用记忆（否决：过度降级，public 原子仍应可用）。

## 代价（需对主人说明）

`tool_schema_mode=full` 时 `web_lookup` 常驻工具集，导致 R1 类内容在主人私聊中**基本不会注入**。这是隐私优先的保守设计，不是 bug。
